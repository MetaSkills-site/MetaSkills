# Iterative PDF Import & Non-MCQ Support - Implementation Context

This folder contains all the research, analysis, and execution plans for the **Iterative PDF Import** feature. 

## Feature Goals
1. **Iterative Processing:** Move from batch PDF parsing to a page-by-page generator flow to handle large documents without timeouts or memory crashes.
2. **Non-MCQ Support:** Enable full support for Short Answer (SA) and Fill-in-the-Blank (FITB) question types in the bulk import workflow.
3. **Continuity Handling:** Use a "Sliding Window" AI strategy to merge questions split across page boundaries.
4. **Streaming UI:** Provide real-time per-page progress updates to the user.
